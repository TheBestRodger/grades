1.	ОБЩИЕ ПОЛОЖЕНИЯ
1.1.	Научно-образовательный центр «Электронный университет» (НОЦ ЭУ) является самостоятельным структурным подразделением МГТУ им.Н.Э.Баумана (далее - Университет)
1.2.	Целью деятельности НОЦ ЭУ является разработка интегрированной информационной системы «Электронный Университет» для автоматизации бизнес процессов и организации управления Университетом по всем сферам его деятельности, а также предоставление разнообразной информации на основе цифровых информационных ресурсов.
1.3.	НОЦ ЭУ возглавляет Директор, который непосредственно подчиняется Проректору по информатизации.
1.4.	НОЦ ЭУ в своей деятельности руководствуется: законодательством Российской Федерации;
- Уставом МГТУ им.Н.Э.Баумана
локальными нормативными актами Университета Настоящим положением.
2.	ОСНОВНЫЕ ЗАДАЧИ
2.1.	Основной задачей НОЦ ЭУ является создание интегрированной информационной системы «Электронный Университет».
2.2.	Задачами НОЦ ЭУ являются
•	Разработка и внедрение цифровых технологий для автоматизации бизнес процессов управления Университетом по всем сферам его деятельности;
0	Реорганизация бизнес процессов Университета на основе возможностей информационных (цифровых) технологий для приведения их к единым стандартам качества;
0	Организация управления качеством образования посредством эффективной организации и контроля учебного процесса на основе использования цифровых технологий;
•	Организацию управления научными исследованиями на основе внедрения цифровых технологий;
•	Исключение «бумажных» технологий;
0	Развитие электронных сервисов для сотрудников и студентов;
•	Разработка системы контроля и управления доступом в Университет.
2.3.	Задачами НОЦ ЭУ по реализации ИС ЭУ являются:
•	Создание компьютерных программ на современных технологиях и постоянное развитие и совершенствование системы «Электронный Университет».
•	Развитие средств интеграции с другими информационными системами
3.	СТРУКТУРА
3.1.	Структуру и штатное расписание НОЦ ЭУ утверждает ректор Университета в установленном в Университете порядке.
3.2.	В структуру НОЦ ЭУ входят:
•	Отдел Проектирования и разработки
3
•	Отдел Системной интеграции
•	Отдел Разработки систем управления безопасностью
4.ФУНКЦИИ
В целях выполнения задач НОЦ ЭУ осуществляет следующие функции:
•	Разработка общей концепции развития цифровой среды по различным направлениям деятельности Университета
•	Определение единой технической политики по реализации и развитию системы «Электронный университет»
•	Определение внутренних стандартов по информационному взаимодействию между отдельными функциональными подсистемами
•	Определение внутренних стандартов по форматам обмена данными
•	Определение единого стандарта идентификации всех объектов информационных систем
•	Организация управления разработкой информационных подсистем в рамках общей технической политики
•	Автоматизация основных бизнес процессов учебного процесса
•	Автоматизация основных бизнес процессов научного-исследовательского блока
•	Автоматизация отдельных бизнес процессов административного блока
•	Переосмысление бизнес процессов с учётом возможностей их автоматизации
•	Оптимизация бизнес процессов на основе их автоматизации
5.ВЗАИМОДЕЙСТВИЕ
Взаимодействие НОЦ ЭУ со структурными подразделениями Университета определяется задачами и функциями, возложенными на него настоящим Положением.
